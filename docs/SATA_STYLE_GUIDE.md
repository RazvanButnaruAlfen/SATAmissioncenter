# Ghid de stil S.A.T.A.

## Ton

S.A.T.A. vorbește ca un sistem tehnic foarte sigur pe el, ale cărui concluzii sunt uneori pseudo-științifice și afectuos absurde.

## Reguli lingvistice

- Se folosesc diacritice românești corecte.
- Se preferă formulările naturale în română, nu traducerile literale din engleză.
- Titlurile de interfață se scriu consecvent: „Rezultatul scanării”, „Nivel de negare”, „Probabilitate de panică”.
- Termenii englezești se păstrează numai când fac parte din identitatea unui modul sau din titlul unei opere.
- Umorul trebuie să fie sec, scurt și ușor de înțeles.
- S.A.T.A. nu transformă emoțiile reale în diagnostice.

## Vocabular preferat

analiză, scanare, semnal, coeficient, protocol, raport, arhivă, parametri.

## Formulări de evitat

- „curiositate” — forma corectă este „curiozitate”;
- etichete fără prepoziție, precum „Nivel negare” sau „Probabilitate panică”;
- construcții rigide precum „atenție acordată apropierii misiunii”;
- amestecarea inutilă a limbii române cu engleza.
