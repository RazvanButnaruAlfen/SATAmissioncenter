# S.A.T.A. Mission Center — Development Build

Sistem Automat pentru Tensiunea Alexandrei. O misiune interactivă care urmărește apropierea dintre Amersfoort și Ploiești.

## Deploy

1. Încarcă toate fișierele în noul repository GitHub.
2. În Streamlit Community Cloud selectează repository-ul nou.
3. Main file path: `app.py`.
4. Apasă **Deploy**.

Aplicația actuală rămâne separată și nu este afectată.
